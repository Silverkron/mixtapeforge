01

Disponibilidad actual

Los paquetes públicos para macOS y Windows x64 están disponibles arriba. La aplicación macOS está firmada ad hoc y no notarizada; Windows puede avisar de que el instalador no está firmado. Los paquetes Linux aún no están publicados, aunque la configuración de compilación está incluida en el código.

02

Compilar desde el código

Instala Node.js 22, Rust estable, CMake y los requisitos Tauri del sistema. Linux también necesita cabeceras ALSA. Ejecuta estos comandos desde la raíz del repositorio. La vista de navegador no ofrece audio ni archivos nativos.

npm ci
npm run desktop
npm run desktop:build
03

Antes de grabar

Conecta la salida de audio a LINE IN, empieza a volumen moderado y comprueba REC LEVEL con una prueba corta. La aplicación no pulsa REC físicamente.
