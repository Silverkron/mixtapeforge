01

Disponibilité actuelle

Les paquets publics pour macOS et Windows x64 sont disponibles ci-dessus. L’application macOS est signée ad hoc et non notariée ; Windows peut signaler que l’installateur n’est pas signé. Les paquets Linux ne sont pas encore publiés, mais la configuration de compilation reste incluse dans les sources.

02

Compiler les sources

Installez Node.js 22, Rust stable, CMake et les prérequis Tauri du système. Linux nécessite aussi les en-têtes ALSA. Lancez ces commandes à la racine du dépôt. L’aperçu navigateur ne fournit pas les fonctions audio et fichiers du bureau.

npm ci
npm run desktop
npm run desktop:build
03

Avant de lancer REC

Reliez une sortie audio à LINE IN. Commencez avec un volume modéré et faites un essai du niveau d’enregistrement. L’application ne commande pas le bouton REC physique.
