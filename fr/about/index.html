Pour ceux qui enregistrent vraiment des cassettes.

Un atelier local pour transformer vos morceaux en une cassette à écouter.

01

Le projet

MixtapeForge réunit préparation des faces, traitement audio, profils de mesure et jaquettes dans un même projet de bureau.

02

Ouvert et local

Le code original est sous GPL-3.0-only. Les traitements restent sur l’ordinateur. Les bibliothèques, polices, plugins et l’utilitaire Type B séparé conservent leurs licences.

03

Notre méthode éditoriale

Les guides associent procédures pratiques, documentation constructeur et questions des communautés. Les illustrations ne sont pas des preuves de mesure. Consultez le manuel propre à votre appareil.

04

Première édition

Cette édition multilingue est assistée par des outils génératifs, sans revue indépendante de laboratoire ni révision native complète. Aucun essai matériel n’est revendiqué sans documentation explicite. Les corrections reproductibles sont bienvenues via le dépôt.
