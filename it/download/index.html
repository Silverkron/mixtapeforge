MixtapeForge è un prototipo desktop open source. Audio e progetti restano sul tuo computer.

MixtapeForge v0.1.0

Scarica MixtapeForge 0.1.0

Scegli il pacchetto per il tuo computer. Le build macOS sono firmate ad hoc e non notarizzate, quindi macOS può chiedere di confermare il primo avvio. Windows può mostrare un avviso SmartScreen per questo prototipo non firmato. Verifica il file scaricato con SHA-256.

01

Disponibilità attuale

I pacchetti pubblici per macOS e Windows x64 sono disponibili qui sopra. L’app macOS è firmata ad hoc e non notarizzata; Windows può segnalare che l’installer non è firmato. I pacchetti Linux non sono ancora pubblicati, ma la configurazione di build è inclusa nei sorgenti.

02

Compila dai sorgenti

Installa Node.js 22, Rust stabile, CMake e i prerequisiti Tauri del tuo sistema. Su Linux servono gli header ALSA. Esegui questi comandi dalla radice del repository. L’anteprima browser non offre audio e operazioni desktop.

npm ci
npm run desktop
npm run desktop:build
03

Prima registrazione

Collega un’uscita audio a LINE IN, parti con volume moderato e fai una prova breve del livello REC. L’applicazione non può premere il pulsante fisico della piastra.
