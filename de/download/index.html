01

Aktuelle Verfügbarkeit

Öffentliche Pakete für macOS und Windows x64 sind oben verfügbar. Die macOS-App ist ad-hoc signiert und nicht notarisiert; Windows kann den unsignierten Installer melden. Linux-Pakete sind noch nicht veröffentlicht, die Build-Konfiguration ist jedoch im Quellcode enthalten.

02

Aus den Quellen bauen

Installiere Node.js 22, stabiles Rust, CMake und die Tauri-Voraussetzungen deines Systems. Linux benötigt ALSA-Entwicklungsheader. Führe diese Befehle im Repository-Hauptverzeichnis aus. Die Browser-Vorschau bietet keine nativen Audio- oder Dateifunktionen.

npm ci
npm run desktop
npm run desktop:build
03

Vor der Aufnahme

Verbinde den Audioausgang mit LINE IN. Beginne mit moderatem Pegel und einer kurzen Probe. Die Anwendung betätigt nicht die physische REC-Taste des Decks.
