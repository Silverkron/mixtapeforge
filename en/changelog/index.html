What is on the workbench.

An honest snapshot of the prototype, separate from signed public releases.

01

Prototype 0.1

Two-side planning, local audio preparation, native output, project recovery, level processing, ten-band EQ, compression, an optional Type B encoder, one VST3 effect slot, guided calibration profiles and printable J-cards.

02

Cover and workflow refinements

Nine artwork styles, six bundled fonts, custom palettes, grayscale output and system printing. The workspace layout aligns Mixtape, Calibration and Covers.

03

Still being qualified

Public installer distribution, signing and notarization, Windows/Linux hardware verification and independent Type B compatibility tests remain separate release work. This page does not announce a finished release.
