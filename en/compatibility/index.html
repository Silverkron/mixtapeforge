Know what your setup needs.

A clear distinction between implemented tools, external components and work still being verified.

01

Desktop and browser

Native audio, importing, recording preparation and export require the desktop app. The browser view is a visual preview. Supported desktop targets are macOS, Windows and Linux; macOS is the platform tested locally so far.

02

Audio files

The engine reads common WAV, FLAC, MP3, Ogg Vorbis and AIFF sources through its decoder. Codec variants and damaged files can still fail: keep the originals and test unusual files before a long recording. Prepared playback uses an internal float32 master.

03

Effects and noise reduction

Level processing, compression and a ten-band EQ are integrated. One external stereo VST3 effect can be hosted at a time. The optional Type B helper is included in desktop packaging; Dolby C, Dolby S, dbx and automatic noise-reduction detection are not implemented.

04

Hardware and measurements

Use an audio device with a supported stereo output format and sample rate. Profiles describe the measured record/play chain, not independent factory alignment. Physical cassette transport, recording levels and playback settings remain the responsibility of the deck and user.

05

Languages

The website is available in English, Italian, French, German and Spanish. The desktop interface currently has Italian, English, French and Spanish translations; German website content does not imply a German app interface.
