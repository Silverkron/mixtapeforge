Noise reduction

Software Dolby and dbx: Tools, Formats and Limitations

Choose software by its documented encoder and decoder rather than by a generic noise-reduction label.

MixtapeForge editorial teamUpdated November 1, 20263 min read
In this guide
  1. Choose a tool for the actual format
  2. Decode an existing tape without double processing
← Back to articles
Quick answer

A software codec encodes or decodes a particular noise-reduction format. A denoiser estimates unwanted noise and removes some of it. They are different jobs: a generic “tape hiss” filter does not decode Dolby or dbx.

Before you start
  • Dolby B, C or S: Which Playback Setting Should You Use?

Choose a tool for the actual format

Tool Documented task What to check
DDi Codec B/C encode and decode; standalone application Mode, reference alignment, current OS support
DxII Codec / DxI Codec Respective dbx II / I processing, plus Disc modes I and II are not interchangeable
Satin B-Type and uhx I/II compander models among its effects Avoid additional tape coloration when testing a decoder
libdolbyb Type B library used by MixtapeForge’s optional encoder Library/build availability and hardware comparison

These are not all included in MixtapeForge. Version 0.1 exposes optional Type B · libdolbyb, not C, S or dbx. Its external stereo VST3 slot is not a promise that every NR plugin or format will work correctly.

Decode an existing tape without double processing

You need the matching decoder, an audio interface with stereo line inputs, capture software and headphones.

  1. Connect deck LINE OUT L/R to interface LINE IN 1/2. Select line sensitivity, disable automatic gain and avoid input clipping. The playback-level guide explains why a digital peak reading is not the Dolby reference.
  2. For software decoding, turn the deck’s NR off and select its correct playback EQ. Record an untouched stereo capture at a supported sample rate and 24-bit depth where available. Keep it.
  3. Open a copy in the decoder, choose the actual format and decode direction. Use a documented reference tone if present. Without one, reference adjustment by ear remains an estimate.
  4. Compare quiet and loud passages. Adjust monitoring volume after decoding; do not normalize or EQ the encoded file casually before the decoder.
  5. Save a separate decoded file with mode and reference settings in its notes. Never decode a capture already decoded by the deck again.

For software encoding, the direction reverses: ordinary source → encoder → deck with recording NR off → matching playback decoder. Test a minute before committing a side. If quiet music loses treble, follow tracking checks; increasing final volume does not correct a decoder-reference error.

For hiss reduction without an encoded tape, read about DNL and DNR: these playback filters do a different job from a Dolby decoder.
