01

Current availability

Public macOS and Windows x64 packages are available above. The macOS application is ad-hoc signed and not notarized; Windows may warn about the unsigned installer. Linux packages are not published yet, but the build configuration is included in the source.

02

Build from source

Install Node.js 22, stable Rust, CMake and the Tauri prerequisites for your operating system. Linux also needs ALSA development headers. From the repository root, run the commands below. The browser preview does not provide desktop audio or file operations.

npm ci
npm run desktop
npm run desktop:build
03

Before the first recording

Connect a suitable audio output to LINE IN on the deck. Keep the starting volume low, make a short test and check the record level on the deck. The application cannot press the physical REC button for you.
