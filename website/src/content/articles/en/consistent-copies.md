## Establish one version

Prepare the final A/B order, source files and gaps in MixtapeForge. Save that project and export side masters if you need a fixed audio deliverable. Choose one tape model where possible and make a complete first copy using [a checked recording level](../recording-levels/).

Listen to both sides before duplicating. Record hardware positions and software processing in [your session notes](../mixtape-notes/). If the first tape needs changes, revise the project and replace the reference before numbering copies.

## Repeat and sample-check

1. Label the blank’s copy number before starting, keeping it paired with its case.
2. Restore the same output, volume, REC LEVEL, tape type and NR. If anything moved, repeat the short level test.
3. Record A and B from the approved project or masters, with the same start allowance. Do not add compression or normalization between copies.
4. Check every copy’s beginning, ending, both channels and a known loud passage. For a small run, full listening provides stronger assurance than spot checks alone.
5. Mark a faulty cassette and rerecord or replace it; do not silently change settings just for that tape and call the batch identical.

## Know the practical limit

Equal settings improve consistency, but blanks, transport behaviour and repeated handling can still vary. Compare a suspect copy at similar listening volume before diagnosing EQ differences. A home recording workflow is not the same process as a duplication plant’s high-speed master system.

**Ready to distribute:** approved reference retained, copies identifiable, all A/B endings checked, matching inserts and playback NR. For a larger batch, plan [a small cassette release](../small-cassette-release/).
