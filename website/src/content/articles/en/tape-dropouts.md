## Repeat the same passage

Use headphones and, optionally, capture software such as [Audacity](https://manual.audacityteam.org/man/tutorial_copying_tapes_lps_or_minidiscs_to_cd.html). For capture, connect deck LINE OUT L/R to interface line inputs, choose stereo and avoid clipping. Leave processing unchanged between comparisons.

1. Mark the time of the audible dip. Replay a short section around it once; do not repeatedly run a visibly damaged tape.
2. If the dip occurs at the same musical moment, compare with the original source if available. It may already be in the recording.
3. Try a different known-good cassette with its correct NR/EQ settings. If it also has changing losses, inspect the deck's accessible path and follow [cleaning instructions](../clean-cassette-deck/).
4. If safe and available, compare the suspect tape on a second working deck. Keep the same playback mode.
5. Note whether the loss repeats at the same location, affects one or both channels, or shifts between passes.

## Use the pattern, not a guess

A repeatable loss on two decks points toward recorded damage or the original recording, but does not distinguish them without the source. A loss that moves between passes suggests unstable contact or transport. Multiple tapes failing on one machine shifts attention to that machine.

Stop if tape creases, sheds visible material or starts [tangling](../tape-eating/). A dropout can be made more obvious by NR expansion, but switching NR off is not a repair.

Do not build an EQ correction around brief dips: a fixed boost affects all the healthy music too. Preserve the best intact transfer; editing a damaged moment is a separate restoration decision. Only create a [recording profile](../recording-profile/) once the path produces stable, repeatable results.
