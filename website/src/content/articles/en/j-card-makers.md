## Three practical choices

**MixtapeForge** keeps the cover’s A/B list connected to the recording project. Its nine styles, six title-font choices and custom colours suit a standard insert. It prints directly and exports A4 PDF, editable SVG and text tracklists. Built-in graphical layouts stop at 15 tracks total; they are not free-placement page editors.

**[Damn Simple J-Card Creator](https://github.com/m4ddok87/Damn-Simple-J-Card-Creator)** documents a local Windows workflow with movable text/image boxes, front/spine/back image slots, editable projects and PDF printing export. Its default dimensions differ slightly from MixtapeForge’s. Compare actual case fit rather than assuming interchangeable templates.

**[Inkscape](https://inkscape-manuals.readthedocs.io/en/latest/export-pdf.html)** is useful for vector editing, extra panels and supplier templates. You control physical page dimensions and folds yourself. Keep an SVG master and export a PDF copy; saving only PDF can lose editable information.

## Run the same acceptance test

1. Enter the real longest title, an accented artist name and the full A/B list.
2. Export and reopen the file outside the editor. Inspect missing characters, cropped text and dimensions.
3. [Print at 100% and fit the case](../print-j-card/).
4. Change one song and repeat the export. Count the corrections you must redo; that reveals whether the tool fits regular use.

If the list is too long, follow [the separate-layout workflow](../long-tracklists/) instead of omitting tracks. If using supplied artwork, retain [its permission and credit details](../artwork-credits/).

**Choose the tool that passes your real proof**, not the one with the most attractive empty template.
